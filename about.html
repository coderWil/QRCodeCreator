About

Event QR Code Creator is a free tool for turning event details into a QR code that adds the event straight to a calendar app when scanned – no app, sign-up, or account required.

Fill in a title, location, and start/end time, and it builds a standard iCalendar (.ics) event and encodes it directly into the QR code. Point a phone camera at it, and most phones offer an "Add to Calendar" action right away.

Everything runs in your browser. Event details are never sent to a server. Event Location is remembered between visits using your browser's local storage, so it's already filled in next time – that value stays on your device too and is never sent anywhere.

Website mode skips calendars entirely – it encodes the URL you type directly into the QR code, so the code itself is the link, nothing more.

That makes it a static QR code. A "dynamic" QR service instead points the code at a short link on its own server and only redirects you from there to the real destination – which means that server can change where you land, track every scan, or shut the link off later, all without reprinting the code.

A static code has none of that in between. Scanning it sends a phone straight to the exact URL you entered – no intermediary, no forwarding hop. No one else sees when or how often it gets scanned, and no one but you can ever redirect or disable it, because there's no service in the middle to do so.

The tradeoff: since the URL is baked into the pattern itself, changing the destination later means generating a new code.
